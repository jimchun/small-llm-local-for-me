一、核心理念

Little LLM 不是要造一个更大的模型，而是要让已经存在的小模型变得可信、可用、可溯源。

当前 AI 的困境：云端大模型能力强，但数据要上传、回答不可验证、隐私无法保障。Little LLM 选择另一条路——用本地 1.5B 参数的小模型作为「逻辑核」，负责推理和组织语言；把知识获取「外包」给权威数据源（维基百科、本地知识库），确保每个回答都有据可查。

三、核心模块

3.1 意图路由系统（A/B/C 三分类）

每次查询先进行意图分类，决定调用哪些知识源，避免不必要的检索开销。

意图含义知识源典型问题
A个人记忆/私有文档用户动态记忆"我之前提到的项目"
B公共知识/百科事实维基百科 + 向量库"量子力学是什么"
C公共知识 + 个人情况全部知识源"根据我的背景，该学什么"

3.2 强制引用系统（防幻觉核心）

Prompt 工程中写入铁律：每个事实性陈述必须标注来源编号，无资料时明确兜底。这是 Little LLM 与传统 AI 助手的本质区别——宁可不说，也不编造。

// 强制引用规则（嵌入 Prompt） 1. 只使用提供的参考资料回答 2. 每个事实性陈述标注来源（如 [来源1]） 3. 无相关信息时明确说"根据提供的资料，无法回答" 4. 禁止使用自身知识或推测 5. 多来源冲突时指出差异

3.3 多知识源管理器

可插拔的知识源架构，按权重融合排序：

知识源权重特点权威性
常识缓存1.0100+ 条基础常识，最快响应确定
维基百科0.9联网实时检索，权威百科高
本地向量库0.8用户私有知识，语义检索取决于来源
百度百科(替代)0.7中文知识补充中

3.4 三级向量数据库

基于 ChromaDB 的分层向量存储，模拟 CPU 缓存策略：

层级用途容量上限淘汰策略
L1 热缓存高频访问数据1,000 条LRU（最近最少使用）
L2 主存储用户文档 + 知识缓存10,000 条不自动淘汰
L3 归档预留接口——

查询流程：先查 L1（毫秒级命中）→ 未命中再查 L2 → 合并去重排序。L2 中被访问 ≥3 次的文档自动提升到 L1。

3.5 用户画像系统

三层记忆架构，让 AI 越用越懂你：

层次内容存储
静态画像姓名、职业、背景、偏好JSON 持久化
动态记忆历史问答、交互记录关键词检索 + 时间排序
私有文档用户上传的私人文件向量索引

3.6 智能文件夹监控

用户指定文件夹后，系统后台自动监控文件变更（MD5 哈希比对），仅处理修改过的文件。利用本地 LLM 提取摘要和关键词，自动向量化入库。

3.7 学习缓存系统

高频查询自动沉淀为常识，减少重复推理。支持查询次数统计、过期淘汰、自动提升为永久常识。

六、API 接口

所有接口通过 HTTP JSON 调用，基础地址：http://localhost:9820

核心查询

POST/api/query智能问答（意图路由+多源检索+强制引用）
POST/api/search多知识源搜索（仅检索不生成）

向量库

POST/api/vector/add添加文档到向量库
POST/api/vector/search向量语义搜索
GET/api/vector/stats向量库统计（L1/L2 容量、命中率）
POST/api/vector/auto_promote高频文档自动提升到 L1

用户画像

GET/api/profile获取用户画像
POST/api/profile/update更新静态画像
POST/api/memory/add添加动态记忆
GET/api/memory/search搜索动态记忆

文件夹监控

GET/api/monitor/status获取监控状态
POST/api/monitor/add_folder添加监控文件夹
POST/api/monitor/scan_now立即扫描一次
GET/api/monitor/files已监控文件列表

系统

GET/api/stats系统全局统计
GET/health健康检查

八、用户画像

Little LLM 服务的人群有明确特征——他们在意隐私、讨厌黑箱、需要可信赖的答案。

用户类型核心诉求使用场景
注重隐私的个人用户数据不出本机，AI 辅助不影响隐私日记整理、私人知识检索、学习笔记
知识工作者需要可溯源的准确答案，不要幻觉写作调研、资料整理、事实核查
开发者/技术人员本地可控的 AI 能力，可二次开发代码库文档检索、技术问答、知识库搭建
企业内网场景离线可用、数据合规内部文档管理、规章制度查询、经验传承

留存设计

用户使用越久，系统价值越高——动态记忆积累、私有文档入库、文件夹持续监控、常识自动沉淀。这种「越用越好用」的正反馈是核心留存引擎。

十二、快速开始

环境要求

Python 3.11+、Ollama（本地推理引擎）、Windows 10/11 或 Linux/macOS

安装步骤

# 方式一：一键启动（推荐） 双击 mvp\start.bat # 自动完成：创建虚拟环境 → 安装依赖 → 检查Ollama → 下载模型 → 启动服务 # 方式二：手动安装 # 1. 安装 Python 依赖 cd mvp/backend pip install -r requirements.txt # 2. 安装 Ollama 并拉取模型 # 下载地址: https://ollama.com/download ollama pull deepseek-r1:1.5b # 3. 启动后端 python main.py # → 浏览器打开 frontend/index.html

# 终端 1 - 启动后端 API cd backend python main.py # → API 运行在 http://localhost:9820 # 终端 2 - 启动桌面客户端 cd frontend python gui_client.py
