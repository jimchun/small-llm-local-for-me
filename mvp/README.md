# Little LLM MVP

**本地运行 · 强制引用 · 拒绝幻觉**

一个极简的本地知识问答系统，验证"基于真实资料、拒绝编造"的核心理念。

---

## 快速启动

### 前置要求

1. 安装 [Ollama](https://ollama.com/)
2. 拉取模型：
   ```bash
   ollama pull deepseek-r1:1.5b
   ```
3. 确认 Ollama 运行中：
   ```bash
   ollama run deepseek-r1:1.5b "你好"
   ```

### 启动 MVP

**方式一：一键启动（推荐）**
```cmd
start.bat
```

**方式二：手动启动**
```bash
# 终端1：启动后端
cd backend
pip install -r requirements.txt
python main.py

# 终端2：打开前端
# 用浏览器打开 frontend/index.html
```

访问地址：http://localhost:9821/frontend/index.html 或直接打开 `frontend/index.html`

## 核心功能

### 1. 强制引用机制（防幻觉核心）

系统在调用模型前，会先从维基百科检索相关资料，然后将资料注入 Prompt：

```
你是一个严格基于证据的问答助手。
请仅根据以下【参考资料】回答用户的问题。

要求：
1. 回答必须完全基于参考资料，不得添加任何参考资料之外的内容。
2. 每个事实性陈述后必须标注引用来源，格式为 [来源名称]。
3. 如果参考资料中没有相关信息，必须明确回复：「参考资料中没有相关信息，无法回答。」
4. 不得推测、编造或补充任何信息。
```

### 2. 本地推理

- 模型：DeepSeek-R1:1.5b（通过 Ollama 运行）
- 完全本地，不联网上传任何数据
- 低温设置（temperature=0.1），减少随机编造

### 3. 知识检索

- 知识源：维基百科（中文优先，无结果时回退英文）
- 每次检索 Top 3 相关词条的引言摘要
- 每篇摘要截断至 800 字符，控制上下文长度

## 验证核心功能

### 测试用例

1. **有资料的问题**（应返回带引用的回答）
   - "什么是量子计算？"
   - "TCP和UDP的区别？"
   - "爱因斯坦的相对论是什么？"

2. **无资料的问题**（应回复"无法回答"）
   - "我家门口那棵树多高？"
   - "明天北京天气怎么样？"（维基百科不含实时天气）

3. **边界测试**
   - 空问题（应返回 400 错误）
   - Ollama 未启动（应返回 503 错误）
   - 无网络（维基百科调用失败，应优雅降级）

### API 测试

```bash
# 健康检查
curl http://localhost:9821/health

# 查询接口
curl -X POST http://localhost:9821/query \
  -H "Content-Type: application/json" \
  -d '{"question": "什么是机器学习？"}'
```

## 常见问题

**Q: 模型回答质量很差？**
A: 1.5B 参数模型能力有限，主要用于验证机制。完整版可切换更大模型。

**Q: 维基百科查不到？**
A: 检查网络连接。系统会自动从中文回退到英文，仍无结果则返回"未找到"。

**Q: 端口冲突？**
A: 修改 `main.py` 中的端口号（默认 9821），同步修改 `index.html` 中的 `API_BASE`。
